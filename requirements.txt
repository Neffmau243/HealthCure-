# Instalar:  pip install -r requirements.txt

# ¿POR QUÉ VERSIONES FIJAS (==) Y NO RANGOS (>=)?
#
#   1) REPRODUCIBILIDAD. Con ">=..." una máquina nueva instala las versiones
#      más recientes y el proyecto puede romperse sin que nadie haya tocado
#      el código. Pasó de verdad: un clon limpio instalaba SQLAlchemy 2.1.4
#      en vez de 2.0.36, y el proyecto nunca se probó con esa versión.
#      Estas versiones son las que corren los 76 tests en verde.
#
#   2) WINDOWS + CONTROL INTELIGENTE DE APLICACIONES (Smart App Control).
#      Windows bloquea binarios recién descargados sin reputación con el
#      error "Una directiva de Control de aplicaciones bloqueó este archivo".
#      Le pasa a los .exe que genera pip (uvicorn.exe) y a las DLL
#      compiladas de versiones muy nuevas (SQLAlchemy 2.1.x, pandas,
#      scikit-learn, xgboost). Estas versiones ya están permitidas.
#
#      Si aun así te bloquea algo: crea el entorno con
#      `python -m venv venv --system-site-packages` (reutiliza los paquetes
#      ya instalados y permitidos por Windows).
#
# Al actualizar una versión: correr `python -m pytest app/tests -v` y, si
# pasa, actualizar el número aquí.
# ============================================================
